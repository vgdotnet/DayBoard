# DayBoard - дизайн по макету

Источник - артефакт Design «Часы и уведомления - макет»:
https://claude.ai/artifact/3nyTccdimboQqhFbPCmLzd
Копия файлов макета - в `docs/mockup/` (`*.dc.html` - разметка экранов с инлайн-стилями,
`canvas.json` - расположение артбордов и заметки с объяснением решений).

## Экраны

| Файл | Экран | Размер |
|---|---|---|
| `Main.dc.html` | Главный «Сегодня»: время, карточки поясов, полоса рабочих часов, события и задачи, непрочитанное, нижняя навигация | 390×844 |
| `Inbox.dc.html` | Входящие: одна лента писем и Slack по времени, фильтр Все / Почта / Slack, группы Сегодня / Вчера | 390×844 |

Те же имена с суффиксом `-light` - светлая тема.

## Решения из макета

- Один главный экран без прокрутки. Порядок блоков по частоте взгляда:
  время (каждый раз) → календарь (несколько раз в день) → входящие (по сигналу).
- Полоса рабочих часов показывает, у кого сейчас рабочее время. В коде карточка сворачивается
  нажатием на заголовок до одной строки «Рабочие часы · работают: Гранада, Москва, Лондон»;
  состояние хранится в настройках. Рабочие часы 9-18 по местному
  времени каждого пояса, шкала - сутки домашнего пояса, вертикальная линия «сейчас».
  Пример: Москва (+1 ч) - полоса с 8:00 до 17:00 по Гранаде, то есть left 33,3 %, width 37,5 %.
- Входящие - одна лента из писем и Slack, отсортирована по времени. Своё чтение писем не делаем:
  нажатие открывает письмо или тред в родном приложении (Gmail / Slack).
- На планшете экран «Входящие» не нужен: лента стоит справа от календаря. Боковое меню слева
  вместо нижнего. У ближайшей встречи - прямой переход в Meet. Под событиями - их время в поясе
  собеседника («17:30 - 18:30 · 16:30 в Лондоне»).
- Правка после проверки на Galaxy Tab A7 Lite (04.11.2026, высота всего 601 dp): шапка макета съедала
  половину экрана. В коде планшетный экран устроен так: верхняя строка во всю ширину - крупные часы (72 sp)
  слева по ширине содержимого и три карточки поясов, растянутые до правого края; ниже две равные колонки - слева дневной вид календаря, прижатый
  к часам (без строки задач - на планшете задачи в календаре не показываем), справа полоса рабочих часов и под ней лента непрочитанного. Макет `Tablet.dc.html` остаётся
  референсом по стилю, но не по раскладке.
- Панель «Сегодня» на планшете - дневной вид Google Календаря: одна строка даты в шапке
  со стрелками «предыдущий / следующий день» (в коде стрелки переключают день, на чужом дне
  появляется кнопка «Сегодня», линия «сейчас» показывается только на сегодня), строка задач с круглыми чекбоксами, шкала часов
  (14:00-21:00 на макете, 7 часов; в коде - все сутки с прокруткой, 56 dp на час, открывается
  у линии «сейчас»), цветные блоки событий, красная линия «сейчас».
- Виджет 4×2 - главная ценность: время в поясах и счётчики видны без открытия приложения.
  Нажатие на счётчик открывает Входящие.
- Ближайшее событие выделяется рамкой акцентного цвета и подписью «через N мин · Google Meet».
- Настройки поясов (в коде): справочник городов `data/Cities.kt` с русскими названиями, поиск по русскому
  и английскому имени и по id пояса; домашний пояс - первый в списке (решение 04.11.2026), чтобы сменить дом,
  город перетаскивают наверх; последний оставшийся город не удаляется; порядок меняется перетаскиванием за ручку
  слева (строки фиксированной высоты 48 dp, обмен при проходе половины соседней строки).
- Мессенджеры WhatsApp и Telegram отложены.

## Типографика

Шрифт Inter (400, 500, 600, 700). Размеры:

- Главные часы: 64 px / 600 / letter-spacing −2 (телефон), 88 px / −3 (планшет), 26 px (виджет).
- Часы в карточке пояса: 24 px / 600 (телефон), 32 px (планшет).
- Заголовок экрана: 28 px / 600; заголовок раздела: 15 px / 600 (телефон), 16-18 px (планшет).
- Текст строки: 15 px; превью: 13 px; подписи: 12 px; подписи полосы часов и шкалы: 11 px.

Радиусы: карточки 14 px (телефон) / 16 px (планшет), подложка иконки 10-12 px, фильтр 12 px
с сегментами 9 px, блок события 6 px, чипы 8 px, виджет 28 px.
Отступы экрана: 28 px сверху, 20 px по бокам (телефон); 32 × 36 px (планшет).

## Мигание

- `blink`: opacity 1 → 0.3 → 1, 1,2 с, ease-in-out, бесконечно. На ленте «Входящие» нижняя
  точка 0.25.
- `ping`: кольцо 2 px акцентного цвета вокруг счётчика, scale 1 → 2.4 (2.6 на ленте),
  opacity 0.7 → 0, 1,6 с, ease-out, бесконечно.
- Мигают: счётчики непрочитанного, точки у новых сообщений, точка у пункта «Входящие» в навигации,
  точка в подписи «N новых за 10 мин». Мигание идёт, пока сообщение не прочитано.
- Переключатель «Мигание при новых» в настройках выключает всё мигание; при системной настройке
  «убрать анимации» (prefers-reduced-motion) анимация тоже отключается, кольцо скрывается.

## Майнер: какие приёмы ESP32-ядра применены (проверка 09.11.2026)

| Приём | Kotlin-ядро | Нативное ядро ARMv8 SHA2 |
|---|---|---|
| midstate первого блока один раз на задание | да | да |
| раунды 0-2 второго блока заранее | да | нет: инструкции SHA256H считают по 4 раунда, разрезать группу нельзя |
| свёрнутые константы расписания (w16, w17, c18, c19, c31, c32) | да | расписание строит SHA256SU0/SU1, константы не нужны |
| общее расписание второго блока на все версии заголовка | да | да (строится один раз на nonce) |
| обрыв второго хеша после раунда 60 | да | нет: та же 4-раундовая группа, пропуск 3 раундов из 128 недоступен |
| проверка находок эталонным хешем | да | да (Kotlin, MessageDigest) |
| version rolling: 8 версий на nonce | да | да |

Замеры A/B-чередованием на Galaxy Tab A7 Lite, 8 потоков: нативное без общего расписания 46,1-48,8 MH/s,
с общим расписанием 45,5-46,8 MH/s, с переплетением двух цепочек хеша 45,5 MH/s - разницы в пределах шума,
переплетение не окупается (два расписания по 16 векторов занимают все 32 NEON-регистра); переплетение с
расписанием на лету (около 14 регистров) - 44,9-45,7 против 44,1 MH/s, тоже в шуме. Предел задаёт
пропускная способность SHA-инструкций, расписание считается в свободных тактах.
